📝 Integration Instructions

To integrate the Predictabar widget from test.predictabar.com/widget:

  1. Include the Predictabar SDK script in your HTML
  2. Create a container div for the widget
  3. Initialize the widget with your configuration
  4. Update the widget with progress data
<script src="https://test.predictabar.com/widget.js"></script>
<div id="predictabar-widget"></div>

<script>
  // Initialize Predictabar
  Predictabar.init({
    container: '#predictabar-widget',
    theme: 'modern'
  });
  
  // Update with progress
  Predictabar.update({
    progress: 45,
    estimatedTime: 120
  });
</script>
